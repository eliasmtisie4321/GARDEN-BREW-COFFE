# GARDEN-BREW-COFFE
GardenBrew Coffee Website is my first time building a website, created as a  project using HTML and CSS. It is a multi-page, responsive website for an imaginary coffee business that showcases basic front-end design skills including layout, navigation, and styling.

##  Features

- Responsive navigation bar
- Home, About, Products, and Contact pages
- Featured products section
- “Why Choose Us” section
- Contact form
- Modern coffee-themed design

## Technologies Used

- HTML5
- CSS3
- git
- git hub

##  Purpose of the Project

The goal of this project was to improve my understanding of:
- Website structure using HTML
- Styling with CSS
- Flexbox layouts
- Multi-page website design
- Responsive web design

## How to Use

1. Download or clone the repository
2. Open the project folder
3. Open the `index.html` file in your browser
